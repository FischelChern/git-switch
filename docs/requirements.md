# 需求与验收标准

每条需求都有编号与可执行的验收标准（AT）。实现或修改时必须能对着 AT 逐条自检。
术语以 `AGENTS.md` 第 2 节为准：**平台 / 身份 / 项目**。

状态：`✅ 原型已验证` / `🟡 原型有界面未验证` / `⬜ 未实现`

---

## 一、平台与身份

### R1.1 平台识别 ⬜
项目的平台由其 remote URL 推导，用户不可手动切换。

**AT**
- `git@github.com:o/r.git`、`https://github.com/o/r.git`、`ssh://git@host/o/r.git` 三种写法都能解析出 host
- host 能匹配到已配置平台（含自定义域名如 `gitlab.company.com`）
- 未匹配时提示「未匹配到已配置平台」，不静默归类
- 平台选择器为锁定态，点击提示不可切换

### R1.2 多身份 ⬜
一个平台可挂多个身份，每个身份包含 `user.name`、`user.email`、认证方式、凭据引用。

**AT**
- 同一平台下新增两个身份，切换项目身份时下拉只出现同平台的身份
- 身份列表显示邮箱与认证方式
- 删除被项目使用的身份时，必须要求先改绑或确认级联处理

### R1.3 四种认证方式 ⬜
`Ssh` / `Token` / `Password` / `CredentialFile`。

**AT**
- 选 SSH：显示私钥路径与口令字段，切换时写 `core.sshCommand`
- 选 Token/Password：显示对应字段，凭据入钥匙串，切换时设置 `credential.helper`
- 选凭据文件：显示路径与 helper 选择
- 任何一种方式都不会把凭据原文写进配置文件或日志

### R1.4 凭据安全 ⬜
令牌、密码、私钥口令只进系统钥匙串。

**AT**
- 配置文件里搜不到明文凭据
- 终端回显不含凭据原文
- 界面能显示「已保存 / 未保存」状态
- 提供「测试连接」并显示真实结果

## 二、项目

### R2.1 项目属于平台 ⬜
项目列表按平台展示，中栏显示该平台下的**全部**项目。

**AT**
- 切换身份后，中栏项目数量与内容不变
- 切换身份后，当前选中项目不变
- 左侧身份树的计数为「N 身份 · M 项目」

### R2.2 项目级身份切换 ⬜
切换身份 = 只改变该项目的 git 用户与认证。

**AT**
- 切换 A 项目的身份后，B 项目的 `.git/config` 逐字节不变
- 切换写出的命令与内容可在终端看到
- 刷新后项目的当前身份与切换结果一致

### R2.3 项目级姓名/邮箱覆盖 ⬜ **（P0 回归项）**
项目可单独设置 `user.name` / `user.email`，优先于身份默认值。

**AT**
- 开启覆盖并填写后，`.git/config` 里是对应的自定义值
- 关闭覆盖后，`.git/config` 恢复为身份默认值
- 只覆盖邮箱、不覆盖姓名时，姓名仍取身份默认值
- 覆盖只在目标项目生效，不影响同身份的其他项目

### R2.4 克隆 ⬜
弹窗字段：仓库地址、克隆到、目录名、平台、使用的身份。

**AT**
- 粘贴三种 URL 写法都能识别平台并自动填充目录名
- 目录名可手动覆盖，覆盖后不再被自动改写
- 目标目录已存在同名项目时拒绝克隆并提示
- 克隆成功后新项目出现在中栏，并已绑定所选身份

### R2.5 自动发现身份参与的项目 ⬜
通过平台 API 列出该身份参与的项目，可挑选克隆。

**AT**
- 点击后按当前身份请求对应平台接口，显示 `owner/repo`、描述、星数
- 已在本机的仓库标记为「已在本机」且不可重复克隆
- 接口失败（无权限/网络/限流）时显示真实错误，并保留手动填地址的路径
- 分页能取到多页结果

## 三、git 能力

### R3.1 常用操作 ⬜
获取、拉取、推送、提交、贮藏、分支、合并、变基、重置、标签、日志。

**AT**
- 每个操作执行后终端显示真实命令与真实输出
- 失败时显示 stderr 原文与原因，不显示「成功」
- 提交必须弹出 message 输入，空 message 不允许提交

### R3.2 提交图（git 树）✅
泳道式分支图，含分支、合并、标签引用。tab 名为 `git`。

**AT**
- 合并提交与普通提交视觉可区分
- 分支与标签引用显示在对应提交上
- 泳道在合并处正确收束
- 大仓库（>2000 提交）滚动不卡顿

### R3.3 文件视图 🟡 仅变更（缺「全部文件」）
变更树（M/A/D/R/U）+ 状态色；支持切换「仅变更 / 全部文件」。

**AT**
- 五种状态有区分度
- 重命名显示为一条记录而不是删除+新增
- 切到「全部文件」能看到未变更文件

### R3.4 编辑器 ⬜
语法高亮、行内 blame、引用计数、语法错误标红、撤销、保存、自动保存、自动格式化。

**AT**
- 输入后高亮即时更新，光标位置不跳
- 光标停在标识符上显示「引用 N 处」并高亮所有出现
- 语法错误行左侧标红，修好后立即消失
- `Ctrl/Cmd+Z` 可撤销编辑
- 自动保存开启时，停止输入后写入并显示状态

### R3.5 Diff ⬜
左右对比与上下对比两种模式。

**AT**
- 两种模式可切换且内容正确
- 增行/删行有背景色区分
- 任意变更文件都能看到真实 diff，不是固定样例

### R3.6 Pull Request ⬜
列表、查看、合并、检出。

**AT**
- 显示编号、标题、作者、源分支→目标分支、文件数、CI 状态
- 合并后状态更新为已合并
- 无权限时显示真实错误

### R3.7 终端 ⬜
命令与输出回显，含「问题」「Git 输出」分页。

**AT**
- 每个 git 操作都在终端留下可复制的命令与输出
- 「问题」页列出当前文件的语法问题

## 四、界面

### R4.1 三栏 + 底栏布局 ⬜
左侧平台·身份树、中间项目列表、右侧详情、底部终端。

**AT**
- 窗口缩放到 1280×720 时三栏不重叠、不出现文字互相遮挡
- 底部终端可收起/展开

### R4.2 不污染全局配置 ⬜
**AT**
- 全流程操作后 `~/.gitconfig` 内容与操作前完全一致

### R4.3 搜索与扫描 ⬜
**AT**
- 搜索能按平台名、身份名、项目名过滤
- 扫描指定目录能发现嵌套的 git 仓库并按平台归类

---

## 五、非功能

### R5.1 跨平台 ⬜
macOS / Linux / Windows 均可构建运行。

**AT**
- 三平台 `cargo build --release` 通过
- 配置目录、凭据助手、路径分隔符按平台正确取值
- 中文界面在三平台都不出现方块字

### R5.2 性能 ⬜
**AT**
- 冷启动到主界面 < 1.5s
- 500 个项目的列表滚动不掉帧
- 长任务（克隆、fetch）不阻塞 UI

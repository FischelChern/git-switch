# 原型说明

这里放 GitSwitch 的 HTML 交互原型。**需求变更一律先改这里**，确认效果后再写 Rust。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 最新版，固定入口。改完原型后同步覆盖此文件 |
| `v1.html` … `v8.html` | 历史版本，只增不改，方便回看设计演进 |
| `README.md` | 本文件 |

## 查看方式

直接在浏览器打开 `index.html`，或在 PI-Desktop 里用 `BrowserPreview` 预览（支持改动后热更新）。

## 原型里的数据

全部为前端写死的示例数据（`DB` / `REPOS` / `MOCK_REMOTE` 等），不连接真实 git 仓库，也不会写磁盘。
「获取该身份参与的项目」返回的是 `MOCK_REMOTE`，真实实现走平台 API（见 `AGENTS.md` 6.2 `git/remote_api.rs`）。

## 改原型的注意事项

- 保持与 `AGENTS.md` 第 2 节的术语一致：**平台 / 身份 / 项目**，不要再用「账号」指代身份。
- 身份切换的语义是「换这个项目的 git 用户」，**不得**连带切换项目列表或选中项。
- 平台选择器保持锁定态，不要做成可切换。
- 改完必须实际点一遍关键交互，并把「点了什么、看到什么」写进回复。
